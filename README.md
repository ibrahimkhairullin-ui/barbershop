# Kings Cut — Барбершоп

Тёмный мужской лендинг для барбершопа в центре Москвы.

## Технологии

- HTML5, CSS3, vanilla JavaScript
- CSS Grid + Flexbox
- Flatpickr (календарь)
- Google Fonts (Inter + Playfair Display)

## Секции

- Hero с фоновым фото и CTA
- Услуги и цены (стрижка / борода / комбо)
- Наши мастера (слайдер на мобилке)
- Галерея работ (журнальная раскладка)
- Отзывы клиентов
- Форма записи с кастомными dropdown и календарём

## Запуск

Открой `index.html` в браузере или запусти локальный сервер:

```bash
python -m http.server 8080
```

## Деплой

Перетащи папку на [Netlify](https://app.netlify.com) → Deploy manually.
